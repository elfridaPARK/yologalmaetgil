# 📍 GPX 파일 사용법 정리

YOLO 갈맷길 코스를 더 편하고 안전하게 즐기실 수 있도록 GPX 파일 사용법을 정리했어요.
GPX 파일 하나만 있으면 지도 위에 코스가 그대로 표시돼서, 처음 가는 길도 헤매지 않고 러닝/트레킹을 즐길 수 있습니다.

---

## GPX 파일이 뭔가요?

GPX(GPS Exchange Format)는 코스의 경로·좌표·고도 정보가 담긴 파일이에요. 이 파일을 지도 앱에 불러오면 실제 코스가 지도 위에 선으로 표시되어서, 갈림길에서도 헷갈리지 않고 따라갈 수 있어요.

## GPX 파일 받는 방법

1. 게시물 댓글에 안내된 키워드를 남겨주세요
2. DM으로 코스 정보가 담긴 Notion 페이지가 자동 전송돼요
3. Notion 페이지 안의 GPX 다운로드 링크를 눌러 파일을 저장하세요

---

## 🥇 추천 앱: 코뭇 (Komoot)

국내는 스트라바 지도 지원이 원활하지 않고 나이키 런 클럽은 GPX 자체를 불러올 수 없어서, 갈맷길 같은 국내 트레일 코스는 **KOMOOT** 가장 추천드려요.

### 방법 1. 공유 시트로 바로 열기 (가장 간단)

1. 저장된 GPX 파일을 [파일] 앱에서 찾기
2. 파일을 길게 눌러 **공유** 버튼 탭
3. 공유 목록에서 **Komoot** 선택 (목록에 안 보이면 옆으로 스크롤해서 '더보기' 확인)
4. 자동으로 코모트 앱이 열리며 코스가 '투어'로 저장돼요

### 방법 2. 앱 안에서 직접 불러오기

1. 코모트 앱 실행 후 로그인
2. 하단 **프로필** → **저장한 루트** 이동
3. 우측 상단 **가져오기** → **파일 가져오기 (GPX, FIT, TCX)** 선택
4. 저장해둔 GPX 파일 선택
5. 스포츠 종류(러닝/하이킹) 선택 후 저장

> 💡 코뭇은 무료 버전도 음성 턴바이턴 내비게이션을 지원해서, 러닝 중에 계속 화면을 안 봐도 갈림길마다 안내해줘요.

---

## 🥈 대안: Maps.me

코모트가 익숙하지 않으신 분들은 Maps.me도 좋은 대안이에요. 오프라인 지도 기반이라 산길처럼 인터넷이 잘 안 터지는 구간에서도 안정적으로 작동해요.

1. 저장된 GPX 파일을 [파일] 앱에서 찾기
2. 파일 길게 눌러 **공유** 버튼 탭
3. 공유 목록에서 **Maps.me** 선택
4. 자동으로 지도 위에 경로가 표시돼요

---

## ⌚ 애플워치 사용자라면

아이폰 KOMOOT 앱으로 GPX 파일을 먼저 불러온 뒤, 워치와 연동된 코모트 앱에서 같은 루트를 열고 시작하시면 돼요. 워치 화면에서도 경로 이탈 알림을 받을 수 있어요.
